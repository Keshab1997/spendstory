# Design Mockups — Direction A · "Light & Clean"

Reference mockups for SpendStory. **These are design-direction references, not production assets** —
the text inside them was generated by an image model, so spellings, currency (£ vs ₹) and merchant
names are placeholders. The real app renders **₹**, localized strings (বাংলা / हिन्दी / English)
and real Indian merchants from code.

**What is authoritative here:** layout, spacing, card style, colour, hierarchy, and the light/dark pairing.

## Locked decisions from the mockups

| Element | Decision |
|---|---|
| Background | Light `#F7F6FC` with a soft violet wash at top · dark `#0E0A2A` |
| Cards | White, radius 22–24, soft **violet-tinted** shadow, no hard borders |
| Hero card | Violet gradient, one huge balance number, two stat pills (teal income / rose spending) |
| Quick actions | 4 rounded square buttons, line icon + label underneath |
| Budget bar | Slim rounded gradient fill; amber at 80%, rose at 100% |
| Transaction row | 40dp pastel circular icon · merchant bold · category+time caption · tabular right amount |
| Amount colour | teal `+` income, rose `−` expense — **sign always visible**, never colour alone |
| Bottom nav | Floating rounded bar, 4 items, icon + label, active = teal |
| Motion | Count-up, bar fill, list stagger. Nothing flashy. |

## Theme rule

One layout, two token sets. No screen reads a hardcoded colour — everything comes from
`Theme.of(context).extension<SsColors>()`. Golden tests render **every screen in both brightnesses**.

Not mockups. These are captured from the real Flutter build running in a browser
via `tool/see_screen.py`-style headless capture, in Bengali, with demo data:

| `final-txlist-light.jpg` / `final-txlist-dark.jpg` | S-10 Transactions — grouped by day |
| `final-insights-light.jpg` / `final-insights-dark.jpg` | S-17 Insights — donut, ranking, six-month trend |
| `final-settings-light.jpg` / `final-settings-dark.jpg` | S-20 Settings — theme + language switches |
| `final-pro-light.jpg` | S-22 Pro paywall |

The full board is `docs/live-app-board.html`.

**Why they exist:** an AI mockup (in `light/`, `dark/`, `explored/`) shows intent;
these show what shipped. When the two disagree, these win — and the difference is
usually a bug. The first capture of `final-insights-light` had a blank rectangle
where the trend chart should be, which is how the JavaScript bit-shift bug in
`MiniBars` was found.
